Problem

Solution

A committed tiers.json; Rust/TS/Python read it (or a CI check asserts they match before merge).

Wins

  • ↳ Change a tier in one place, not three
  • ↳ CI catches drift the unit tests can't
  • ↳ The site, the proxy, the CLI can't disagree
